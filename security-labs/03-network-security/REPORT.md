# 네트워크 보안 실습 실습 보고서

최정원 | 교육 실습 | 기간 2025.08.13~2025.08.25 | 정리일 2026.11.09

## 목적

가상 실습 환경에서 서비스 노출과 패킷을 살펴보며 TCP/IP와 접근 가능 범위를 학습한 실습입니다.

## 기존 포트폴리오에 기록된 내용

도구: Nmap, Wireshark, VirtualBox

- 포트 스캐닝 및 서비스 탐색
- 패킷 분석을 통한 의심 트래픽 추적
- TCP/IP 구조와 보안 위험 요소 학습

위 내용은 [기존 노션 기록](https://app.notion.com/p/28b09f14126e8181a60fd570e2e95489)에 있는 실습 요약입니다. 작업 명령·설정·원본 결과와 본인의 독립 수행 범위는 아직 확인되지 않았습니다. 팀장이나 실무 운영 역할을 임의로 부여하지 않습니다.

## 작업 과정을 보여주는 정리 방법

다음 절차는 기록을 보완하거나 재실습할 때 사용할 확인 방법입니다. 당시 수행한 절차나 이번에 완료한 테스트로 간주하지 않습니다.

1. VM 역할과 망 모드를 그림·표로 남깁니다.
2. 허가된 실습 대상과 확인 포트를 정합니다.
3. 서버 리슨 상태와 클라이언트 관찰을 대조합니다.
4. 같은 요청을 Wireshark로 확인하고 프레임 번호를 기록합니다.
5. 정책을 바꿨다면 변경 전후·허용/비허용·정상 통신을 각각 비교합니다.

## 증거별 검토 항목

| ID | 항목 | 확인할 내용 | 필요한 자료 |
|---|---|---|---|
| N01 | 구성도 | VM 역할·망 모드·확인 대상 | Host-only/NAT 등 실제 설정 |
| N02 | 서비스 탐색 | 열린 포트와 실제 프로세스 비교 | 스캔 원본·서버 리슨 목록 |
| N03 | 패킷 분석 | 요청·응답·재전송·RST/무응답 구분 | PCAP·필터·관련 프레임 번호 |
| N04 | 접근 제어 | 허용 출발지와 비허용 출발지 비교 | 정책 원문·각 요청의 응답 |

현재 모든 항목은 원본 증거 미확보 상태입니다. [증거 목록](evidence-register.csv)에 상태를 분리해 기록했습니다.

## 사례를 설명할 때

포트가 열렸다고 보이는 결과를 서버의 실제 서비스와 대조하고, 접속 실패는 RST·무응답·라우팅 문제를 나눠 설명합니다. 과거 결과가 없으므로 특정 포트의 발견 결과는 쓰지 않습니다.

[사례 기록 양식](../templates/CASE_RECORD.md)에는 상황, 직접 한 일, 도움받은 방법, 실제 결과를 작성합니다. 기억하지 못하는 원인은 확인되지 않음으로 남기고, 제안한 개선책을 적용 완료로 바꾸지 않습니다.

## 결과와 한계

Nmap 결과와 PCAP, 실제 네트워크 구성과 방화벽 변경 기록이 없습니다. 열린 포트는 곧 취약점이 아니며 무응답만으로 방화벽 차단이라고 확정하지 않습니다. 저장소의 Kali 하드닝 스크립트는 별개 자료이고 이 교육 실습의 실행 증거가 아닙니다.

현재 결론은 해당 주제의 교육 실습 요약이 존재한다는 수준입니다. 취업 제출 시 수행 사실을 뒷받침할 자료가 있는 사례부터 강조하는 것이 적절합니다.
