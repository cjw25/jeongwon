# 데이터베이스 보안 실습 실습 보고서

최정원 | 교육 실습 | 기간 2025.07.17~2025.07.25 | 정리일 2026.11.09

## 목적

DB의 인증·권한·쿼리 처리·전송 보호·감사 기록을 살펴보는 교육 실습입니다.

## 기존 포트폴리오에 기록된 내용

도구: 기존 본문: MySQL/PostgreSQL, Docker, Wireshark, VirtualBox. 유형 태그: MySQL/MongoDB 등. 실제 사용 DB·버전은 추가 확인 필요

- 계정 생성·접근 제어·최소 권한 설정
- 입력 검증과 Prepared Statement 학습
- TLS·컬럼 암호화 적용 검증에 관한 기존 기록
- 접속·쿼리 로그 수집과 분석에 관한 기존 기록

위 내용은 [기존 노션 기록](https://app.notion.com/p/2ae09f14126e8034a883c2c6ec15f0b9)에 있는 실습 요약입니다. 작업 명령·설정·원본 결과와 본인의 독립 수행 범위는 아직 확인되지 않았습니다. 팀장이나 실무 운영 역할을 임의로 부여하지 않습니다.

## 작업 과정을 보여주는 정리 방법

다음 절차는 기록을 보완하거나 재실습할 때 사용할 확인 방법입니다. 당시 수행한 절차나 이번에 완료한 테스트로 간주하지 않습니다.

1. 실제 사용한 DB 제품·버전·배포 방식을 먼저 확정합니다.
2. 별도 실습 계정과 가상 데이터를 사용합니다.
3. 부여 권한과 허용·거부 결과를 함께 기록합니다.
4. 애플리케이션의 파라미터 바인딩 코드를 확인합니다.
5. TLS 세션과 인증서 검증을 확인하고 로그 지원 범위를 기록합니다.

## 증거별 검토 항목

| ID | 항목 | 확인할 내용 | 필요한 자료 |
|---|---|---|---|
| D01 | 최소 권한 | 실습 계정의 권한과 허용/거부 결과 | DB 종류·버전·권한 조회 |
| D02 | 파라미터 처리 | 문자열 결합과 값 바인딩 구분 | 본인 작업 코드·동일 입력 비교 |
| D03 | TLS | 인증서 검증과 세션 암호화 상태 | 클라이언트 옵션·세션 정보 |
| D04 | 감사·암호화 | 로그 지원 범위·키 관리·저장 값 | 제품/플러그인·비식별 출력 |

기존 실습 캡처 1장을 추가했습니다. 아래 점검 항목 전체가 증명되는 것은 아니며, 화면으로 확인되는 범위는 별도 해설을 참고합니다. [증거 목록](evidence-register.csv)에 상태를 분리해 기록했습니다.

## 사례를 설명할 때

권한 개선 사례는 변경 전 권한, 변경 후 권한, 허용돼야 할 조회와 거부돼야 할 작업의 결과가 모두 필요합니다. TLS는 암호화 상태와 서버 신원 검증을 나눠 확인합니다.

[사례 기록 양식](../templates/CASE_RECORD.md)에는 상황, 직접 한 일, 도움받은 방법, 실제 결과를 작성합니다. 기억하지 못하는 원인은 확인되지 않음으로 남기고, 제안한 개선책을 적용 완료로 바꾸지 않습니다.

## 결과와 한계

기존 본문은 ‘권한 과다 발견→권한 축소’, ‘Prepared Statement 수정으로 취약점 제거’, ‘TLS 적용으로 해결’을 주장하지만 전후 증거가 없습니다. 완료된 성과로 확정하지 않습니다. 본문과 태그의 DB 제품도 달라 실제 환경을 확인해야 합니다. POS 업무의 MySQL 정보 조회·수정과 이 교육 실습은 별개의 경험입니다.

기존 실습 요약 외에 노션의 원본 캡처 1장을 확보했습니다. 화면에서 확인되는 작업과 추가 증거가 필요한 주장을 구분했습니다. 취업 제출 시 수행 사실을 뒷받침할 자료가 있는 사례부터 강조하는 것이 적절합니다.
