# 실제 사례 기록 양식

상태: 미작성. 완료 사례나 테스트 결과가 아닙니다.

## 실습 환경

- 수행 날짜와 시간대:
- 제품·버전·도구:
- 교육용 대상과 구성:
- 원본 증거 파일과 해시:

## 상황과 기대 결과

무엇을 확인하려 했고 정상이라면 어떤 결과가 나와야 했는지 적습니다.

## 직접 한 일

직접 입력한 명령·설정·코드·분석 절차와 순서를 적습니다. 강사 설명을 따라 한 부분과 스스로 판단한 부분을 구분합니다.

## 도움받은 과정

강사·팀원·AI에게 무엇을 보여주고 어떤 제안을 받았는지, 적용 전에 무엇을 확인했는지 적습니다.

|---|---|---|---|

## 원인 판단과 수정

확인된 사실과 추정을 나눕니다. 수정하지 않았다면 개선 제안으로만 표시합니다.

## 재확인

같은 조건의 재현 결과와 정상 기능 영향, 남은 문제를 적습니다. 미실행이면 미실행으로 적습니다.
